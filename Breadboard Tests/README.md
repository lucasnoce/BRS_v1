# Objective
This folder/branch is intended to be used in testing during development and shall not be included in main or dev branches. This branch should be kept updated in relation to dev branch, so that new tests can be added and performed. This test project is based on the STM32F103C8T6 MCU (blue pill) to enable simulation and communication tests with various devices, which are not yet available to me.
